MASALAH SEKARANG:
Kami tidak bisa login untuk testing karena backend block login tanpa email verification. Register berhasil, tapi login ditolak dengan error "Email belum diverifikasi".

SOLUSI TERCEPAT:
Tolong jalankan database seeder di production server:
```
php artisan db:seed
```

Ini akan create akun testing (buyer@radar.test, merchant@radar.test, admin@radar.test) dengan email sudah verified.

ALTERNATIF (kalau seeder tidak bisa):
Manual update database:
```
UPDATE users SET email_verified = 1 WHERE email = 'test@example.com';
```
